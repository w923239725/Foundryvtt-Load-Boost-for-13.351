# Foundryvtt Load Boost for 13.351

[English](README.en.md)

本项目将一次 Foundry VTT 加载排查中的可分享成果分为四部分。**不是一键加速包，也不是保证兼容所有世界的正式发行版。**
资料已脱敏；配置示例统一使用 `vtt.example.com`、回环地址和通用目录。没有原服务器的凭据、世界数据、IP、域名或进程导出。

## 四个子项目

1. [无 CDN 的 Ubuntu 反代配置](01-ubuntu-direct/README.zh-CN.md)：连接复用、WebSocket、压缩分段兼容。
2. [带 Front Door/类似边缘服务的 Ubuntu 配置](02-ubuntu-edge/README.zh-CN.md)：独立静态路由、健康检查、保守共享缓存策略，含配置前后数据的局限说明。
3. [服务端扩展](03-server-extension/README.zh-CN.md)：C9 登录更新提示抑制与 C5 初始合集索引缓存。需要服务器权限，**不是客户端 mod**。
4. [Babele 2.7.5 修改文件](04-babele-patch/README.zh-CN.md)：非合集结果不等待翻译、并发初始化合并。只分发两份带归属说明的修改文件，不重复打包上游整个模组。

每部分都有 `README.zh-CN.md` / `README.en.md` 给人类阅读，
`AGENTS.zh-CN.md` / `AGENTS.en.md` 给 AI 阅读。配置文件中的注释以中文为主，英文说明解释相同配置行为。

## 已知版本与证据状态

历史环境：Ubuntu 22.04、Nginx 1.18、Foundry **13.351**（包版本13.351.0）、Node **20.18.0**、PF1 **11.11**、
Babele **2.7.5**、lib-wrapper **1.13.5.1**。不提供 Windows 部署版本。

- C5/C9 原始固定路径实现曾在测试服验证并应用到原部署环境。
- Babele 第二候选通过隔离译文、完整GM、早期请求及回退演练；**未在原生产环境上线**。
- 本次分享包的示例路径、通用入口、Nginx/边缘模板是重新整理的版本。**只做静态整理和敏感信息检查，不重新运行服务器、配置验证或性能测试。** 历史结果不能冒充分享包已通过新部署验证。
- 本项目不包含任何需要手动授予的服务器操作权限，不包含自动安装、发布或推送工作流。
