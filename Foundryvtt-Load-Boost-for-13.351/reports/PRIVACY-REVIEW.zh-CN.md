# 分享版静态隐私与内容检查

[English](PRIVACY-REVIEW.en.md)

## 范围与结论

检查范围为本分享目录及其四个子项目，不是原服务器或原实验资料目录。
检查包含文件清单、已知部署标识扫描、密钥/凭据模式、域名/IP/机器路径、JSON、文档链接和分发摘要。
**本轮未发现已知原部署的真实IP、域名、账号、世界名、私钥、访问令牌或会话标识残留。**
这是有界静态审阅，不是“绝对无秘密”的保证，也不是服务安全或配置可运行认证。

## 已处理和有意保留

| 类别 | 分享版处理 |
|---|---|
| 原站点与主机地址 | 使用`vtt.example.com`、`127.0.0.1`和文档保留地址`192.0.2.10` |
| 个人目录/实例 | 改为`/opt/foundry`、`/srv/foundry-data`等通用Ubuntu位置；不带个人home路径、真实PM2名称 |
| 配置/证书 | 仅示例字段和证书路径；没有完整私有options、证书正文、私钥、PM2 dump或Azure资源导出 |
| 世界及实验记录 | 只保留匿名化数量/耗时摘要；无角色名、文档ID、聊天内容、原始浏览器轨迹或世界数据库 |
| Babele归属 | 保留公开作者、上游项目/许可URL和修改说明；这些不是用户部署身份 |
| 技术标识 | 保留软件版本、文件摘要、代码内变量、socket.io路径以及公开PF1讨论链接 |
| 日后运行数据 | 实际deployment.json、日志、备份、凭据等应保留在私有位置；gitignore只是辅助，不防止强制添加或手动上传 |

域名扫描结果中的GitLab、Foundry和Creative Commons链接用于来源/许可。
`1.13.5.1`是lib-wrapper版本，不是服务器IP。代码中的token/contextToken是程序变量，不是嵌入的访问凭据。
示例`.pem`路径不包含证书/私钥文件。没有Windows部署版本。

## 静态一致性

- 每个子项目提供中文/英文人类说明与AI说明，目录入口链接到对应文档。
- JSON示例为严格JSON；没有向Foundry options中插入无效注释。
- C5两份库与历史最终版本逐字节一致；新通用入口/C9包装单独标为未实机复验。
- Babele分享文件去掉新增归属注释后与历史候选一致；manifest分别记录原版、无头候选和本分享文件摘要。
- 01/02是互斥模板；`.link`不是可加载配置；Cloud JSON不是可直接导入资源的格式。
- 初期缺失的世界ready指标明确保留为空/不可比较；不同阶段与实验的耗时不相加。

本次没有启动服务、连接服务器、运行预加载器、执行Nginx检查、性能测试或重新部署。
没有创建Git仓库/远端、提交、推送、Gist或Release。
2026-10-12按所有者最新要求：独立代码/配置改用MIT，文档及Babele派生代码保留CC BY 4.0。
已补许可全文、双语范围和相邻源码许可通知，并更新Foundry有效许可链接；许可核对见[LICENSE.md](../LICENSE.md)。
本轮许可整理不改变运行源码字节。公开作者/致谢标识属于应保留的第三方归属，不是原服务器隐私。

## 使用者后续新增内容

复制并修改配置后，原占位符可能变成真实数据。每次分享前都应重新检查整个目录及Git历史，
尤其是私有配置、日志、证书、云资源ID、备份和意外附带的压缩包。
不要将此报告当作对以后新增文件的检查结论。
